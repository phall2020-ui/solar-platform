# Solar Toolkit Database Contents

## Database Location
Path: ~/.solar_toolkit/plant_registry.sqlite

## Database Schema

### Table: plants
Stores information about registered solar plants.

Columns:
- alias (TEXT, PRIMARY KEY): Human-readable plant identifier
- plant_uid (TEXT, NOT NULL): Unique plant ID (e.g., ERS:00001)
- inverter_ids (TEXT): JSON array of inverter device IDs
- weather_id (TEXT): Weather station device ID
- dc_size_kw (REAL): DC nameplate capacity in kilowatts
- created_at (TIMESTAMP): Record creation timestamp

## Viewing Database Contents

You can query the database using:

1. CLI Command:
   ```bash
   python3 entry_point.py store-list
   ```

2. Direct SQLite:
   ```bash
   sqlite3 ~/.solar_toolkit/plant_registry.sqlite "SELECT * FROM plants;"
   ```

3. Python:
   ```python
   import sqlite3
   conn = sqlite3.connect('~/.solar_toolkit/plant_registry.sqlite')
   cursor = conn.cursor()
   cursor.execute('SELECT * FROM plants')
   print(cursor.fetchall())
   ```
